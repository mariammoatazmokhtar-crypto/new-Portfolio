# Mariam Moataz — Portfolio

Personal portfolio website for Mariam Moataz, Game Developer.

## Live Demo
After enabling GitHub Pages (see below), your site will be live at:
`https://<your-github-username>.github.io/<repo-name>/`

## Files
- `index.html` — the full site (HTML, CSS, and JS all in one file)

## How to publish with GitHub Pages
1. Create a new repository on GitHub (e.g. `portfolio`).
2. Push this folder's contents to it (see commands below).
3. On GitHub: go to **Settings → Pages**.
4. Under "Build and deployment", set **Source** to `Deploy from a branch`.
5. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
6. Wait a minute, then visit the link GitHub gives you.

## Push commands
```bash
git init
git add .
git commit -m "Initial commit: portfolio site"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
